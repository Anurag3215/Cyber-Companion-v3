# Cyber Companion — User Personas

This document defines target user archetypes to inform UX decisions, plain-language translation requirements, and feature design across mobile and web platforms.

---

### Persona 1: Aisha Sharma — The College Student
- **Age**: 20  
- **Occupation**: Undergraduate Student (Non-technical major)  
- **Technical Literacy**: Moderate (frequent smartphone user, active on social media)  
- **Pain Points**:
  - Connects to public Wi-Fi in cafes, libraries, and campus hotspots without assessing security risks.
  - Scans promotional QR codes on flyers and restaurant tables quickly without inspecting landing URLs.
  - Gets overwhelmed by technical security jargon ("MitM", "SSL stripping", "phishing certificate").
- **Goals**:
  - Immediate visual feedback on network and link safety.
  - Zero disruption to daily routine unless a high-risk vector is detected.
- **Cyber Companion Value**:
  - Instant Wi-Fi security badge upon connection.
  - Pre-flight QR scan safety checks with clear explanation cards.

---

### Persona 2: Rajesh Patel — The Small Business Owner
- **Age**: 48  
- **Occupation**: Retail Merchant & Entrepreneur  
- **Technical Literacy**: Basic to Intermediate  
- **Pain Points**:
  - Uses personal smartphone for business banking, UPI payments, and supplier messaging.
  - Receives fake delivery and payment links via SMS and WhatsApp.
  - Installs productivity and utility apps without reviewing requested device permissions.
- **Goals**:
  - Protect financial accounts and customer contacts from data leakage.
  - Understand which installed apps have dangerous permissions (e.g. SMS, Contacts).
- **Cyber Companion Value**:
  - Permission Analyzer highlighting apps that combine SMS reading with background network access.
  - URL scanner with homograph lookalike detection for spoofed bank/payment domains.

---

### Persona 3: Margaret Chen — The Senior Smartphone User
- **Age**: 71  
- **Occupation**: Retired Educator  
- **Technical Literacy**: Low  
- **Pain Points**:
  - Vulnerable to scareware notifications and urgency-driven phishing scams.
  - Confused by complex antivirus warning dialogs and configuration settings.
  - Unsure how to improve device security habits.
- **Goals**:
  - Easy-to-read, 6th-grade level security explanations.
  - A single holistic security score with clear, top 3 step-by-step improvement actions.
- **Cyber Companion Value**:
  - High-contrast visual Security Health Gauge (0–100).
  - Micro-learning awareness tips restricted to $\le 60$ words.
